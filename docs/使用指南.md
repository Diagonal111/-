# 拾知 · 个性化学习工作台

根据知识点掌握度、错题与复习间隔，安排今天的学习。当前为个人使用的 v0.2 版本，以 408 原创示例题展示完整体验。

## 启动

Windows 首次使用前请按仓库 README 安装依赖。安装完成后，双击 **`start-study.cmd`** 即可打开浏览器。

地址：<http://127.0.0.1:8765>。程序只监听本机，不需要部署服务器。关闭网页不会关闭后台，在启动窗口按 `Ctrl+C` 可退出。

其他电脑首次运行需要 Python 3.11+、Node.js 20.19+（建议 22.12+ 或更新版本）。脚本会创建虚拟环境、安装依赖和构建前端，需要联网。当前不是免安装的桌面安装包。

开发方式：

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8765 --reload
```

另开终端启动前端：

```powershell
npm run dev
```

打开 <http://127.0.0.1:5173>。前端源码改动后，如通过 8765 访问，需要重新 `npm run build`；开发服务器 5173 自动更新。

## 已实现

- 今日学习工作台：时间预算、任务排序、推荐依据、完成状态、积压提示与规则解释；重排保留已完成任务并扣除其预计用时。
- 题库、知识点地图、错题和到期复习列表，支持按科目和文字筛选。
- 单选、多选、判断题按已核实答案判分；多选采用完全匹配。
- 计算题文字输入、作答照片上传、AI 转写和分步批改；支持修正识别文字后重批。
- 用户确认后更新学习状态，重复确认幂等；保留每次最终结论的修订记录。
- 证据加权掌握度与 1/3/7/14/30/60 天复习间隔；同日重复降低权重，提前练习不延长间隔。
- 标准 Excel 表头直接解析；非标准 Excel、Word 和题目照片通过模型识别。入库前可编辑拆题、知识点和答案。
- 未配置模型时，标准 Excel 仍可导入；其他材料进入人工整理草稿，计算题支持自评。
- 导入校对自动保存，支持暂未填完的草稿；关闭校对窗口前刷新保存，多页面编辑有版本冲突保护。
- 学习记录页支持搜索、状态筛选、分页、查看原始作答和照片、AI 建议与结论修订历史；待确认作答可继续完成。
- 已确认记录可更正判分、撤销及恢复，按原作答日期重新计算掌握度、错题状态和复习日。
- 题目编辑生成新版本，历史作答保留原题和原答案；旧版未确认作答过期，新版本重新安排复习。
- SQLite 本机持久化，题目与作答图片保存在本机；支持完整备份导出、校验预览与恢复，恢复前自动创建安全备份。
- 可配置模型地址和模型名称；API Key 仅存于后台内存，或读取 `STUDY_API_KEY` 环境变量。
- 错题详情支持基于个人题库的 RAG 讲解：使用 SQLite FTS5 与知识点过滤召回相关题目，DeepSeek 生成带题目来源引用的错因分析和再练推荐；检索不到的材料会明确标记，不修改掌握度或复习计划。

## 先体验

首次打开自动载入 16 道原创示例题和一组模拟历史，页面明确显示“示例学习档案”。点击“开始今天的学习”，提交一题并确认，即可看到掌握度与复习日期变化。

在“设置与数据”中可开启个人题库。**首次正式录题或确认导入也会自动移除示例题及其体验作答**，避免模拟历史污染个人记录。导入预览不会立即移除示例数据。

Excel 可以先下载应用中的模板。建议列：标题、题干、题型、A/B/C/D、答案、解析、知识点。单选答案如 `B`，多选如 `A,B`，判断题为“正确”或“错误”。题型支持中文“单选题、多选题、判断题、计算题”。

## 408 基础练习题库

仓库提供可选安装的 100 道原创练习题：数据结构、计算机组成原理、操作系统、计算机网络各 25 道，每科 15 道计算题、7 道单选题、3 道判断题，全部附参考答案与解析。保留原来的 16 道示例题时，题库共 116 道。完整题集可查看 [408 原创练习题库](408原创练习题库.md)。

新增题目的来源标记为“拾知原创练习 · 408 基础 · 非历年真题”，侧重基础巩固。题目涵盖线性表、栈与队列、树、查找、图、数制、性能、存储、流水线、进程调度、页面置换、文件管理、磁盘、网络时延、子网、路由、TCP 与链路协议等；不代表完整考试范围或难度分布。

这 100 道题作为个人练习保留，**以后正式导入不会移除它们及其作答记录**。原来的示例题与示例学习历史仍遵循示例模式的清理规则。新增题目不会生成模拟作答或修改既有学习记录。

其他电脑或新的数据目录可执行以下命令安装；重复执行只补缺失题目，不覆盖你已修改的内容。实际追加前会在数据目录的 `backups` 下生成 `before-practice408_*.zip` 完整备份，可通过设置页选择该文件恢复。

```powershell
.\.venv\Scripts\python.exe -m backend.practice_bank
```

## 配置真实 AI

在“设置与数据 → 连接 AI”填写：

1. 模型服务基础地址，例如服务商提供的 `https://.../v1`。
2. 支持图片输入的模型 ID。
3. API Key。

后台使用 **Chat Completions 兼容接口**，追加 `/chat/completions`，图片按 `image_url` 的 Base64 数据格式传入。服务商需要支持相同协议；只有文本能力的模型不能识别照片。部分兼容服务不支持 `response_format`，可关闭 JSON 模式。

相关题目和照片会发送给所选模型服务。密钥不会返回浏览器、写入数据库或打包到备份。保存配置只保存参数，不会主动发起计费请求。只有用户请求识别、批改或计划解读时才调用模型。

在题目详情中点击“用题库讲解这道题”可以运行 RAG 讲解。系统会召回当前题目同知识点或同科目的已核实题目，并把题目解析、参考答案和已确认作答历史作为模型上下文。模型只能引用召回结果中的题目 ID，后端会过滤越权引用并展示引用标题。当前使用 SQLite FTS5，不需要额外向量数据库；若本机 SQLite 没有 FTS5，则自动使用同知识点的确定性候选补齐结果。

已通过模拟响应验证协议和错误处理，并手动验证过 DeepSeek 真实文本计划解读请求；**没有完成真实服务的识别准确率或批改质量评测**。模型自报判断只作建议，用户确认后才入账。

图片协议依据：[OpenAI Docs · Images and vision](https://developers.openai.com/api/docs/guides/images-vision)。

## 数据位置

默认：`%LOCALAPPDATA%\ShizhiStudy\`，包含 `study.db` 和 `attachments\`。可用 `STUDY_DATA_DIR` 环境变量指定其他目录。时区为 `Asia/Shanghai`。

完整备份需要同时保存数据库与图片，建议使用设置页的“导出数据与照片备份”。在“设置与数据 → 恢复学习备份”选择 ZIP，检查题目、作答和照片数量，勾选替换确认后恢复。程序会校验文件哈希、数据库字段和照片引用，并在恢复前把当前数据备份到 `backups\before-restore-日期-编号.zip`。安全备份可以在设置页下载，再通过同一入口恢复。

恢复会替换题库、作答、计划和导入草稿，沿用本机当前 AI 服务配置和内存密钥。预览有效期 30 分钟；预览后学习数据改变时需要重新检查，避免覆盖新进度。支持上一版导出包，旧数据首次启动会自动补齐版本信息。备份恢复中的数据库或照片写入失败会回滚。

目前恢复限制：ZIP 100 MB、解压后合计 250 MB、数据库 30 MB、最多 5000 个文件。导出包含附件目录中保留的所有 JPG，恢复不会清理目录内未引用的历史照片，安全备份也不会自动清理。

草稿编辑会在停止输入约 0.7 秒后保存；请看到“已保存”再关闭浏览器。关闭校对窗口会等待保存完成。发生冲突时可重新载入已保存版本，界面会先提示放弃当前未保存修改。

## 临时分享给别人体验（Cloudflared）

双击 `start-share.cmd`，或运行：

```powershell
.\.venv\Scripts\python.exe share.py
```

首次会下载并校验官方 Cloudflared 客户端到 `.share/tools`，无需安装系统服务。启动后显示 `https://xxx.trycloudflare.com` 和随机访问口令，把两者发给体验者即可。电脑、后台和分享窗口需要保持运行；临时网址每次启动都会改变。

分享模式在 `.share/sessions` 创建全新的独立数据库，包含 116 道原创示例／练习题和模拟历史，不会复制个人数据或 API Key。访客可浏览书架、科目折叠卡片、答题、自评确认与查看记录；访客共同使用本次演示的数据。材料上传、AI 调用、题目编辑、设置、备份导出与恢复在服务端禁用。访问口令登录有效期 8 小时。

双击 `stop-share.cmd`，或运行以下命令停止分享，个人学习服务不会受影响：

```powershell
.\.venv\Scripts\python.exe share.py --stop
```

当前地址和口令保存在 `.share/status.json`，可用 `share.py --status` 查看；日志位于 `.share/server.log` 和 `.share/tunnel.log`。`.share` 已加入忽略规则。每次分享重新创建示例空间，之前的演示作答仅保存在旧会话目录中。

## 与完整设计相比的边界

这是可运行的基础实现。当前知识点使用可选的 408 分类，每题先绑定一个主知识点；暂未提供知识点编辑、先修图、考试冲刺偏好、锁定任务、细粒度步骤到知识点归因和持久化后台工作队列。

导入与批改请求在页面等待完成；处理中关闭后台需要重新提交。已完成的导入草稿可恢复。首版导入限制单文件 12 MB，单批最多30题，Office 嵌入图片最多8张；复杂公式、合并单元格及图片归属需人工校对。未实现 PDF、旧版 `.doc/.xls` 和手机直连拍照。

学习状态与题目版本已支持回看和重算；暂未提供多道题批量编辑、题目删除、逐版题目差异对比和自动合并多页面草稿。计划算法为启发式基线，掌握度指标不是考试答对概率。

完整设计见 [设计文档](个性化刷题学习系统设计.md)。
